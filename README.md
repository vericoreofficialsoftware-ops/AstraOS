🌌 AstraOS

AstraOS, tamamen sıfırdan geliştirilen bağımsız bir işletim sistemidir.
Kernel, GUI ve kurulum sistemi tek kişi tarafından geliştirilmektedir. Proje halen erken geliştirme aşamasındadır ve aktif olarak güncellenmektedir.

⚡ Özellikler

64-bit mimari desteği

C ile yazılmış özel kernel

C# ile geliştirilen modern grafik arayüz (GUI)

Basit kurulum ekranı (Installer)

Temel VGA grafik sürücüsü

Klavye & mouse desteği (geliştirme aşamasında)

Sıfırdan oluşturulmuş dosya ve sistem mimarisi

📁 Proje Yapısı
AstraOS/
 ├─ kernel/        # Temel çekirdek kodları
 ├─ drivers/       # Donanım sürücüleri
 ├─ ui/            # C# grafik arayüz bileşenleri
 ├─ installer/     # AstraOS kurulum ekranı ve kurulum mantığı
 ├─ boot/          # Bootloader dosyaları
 ├─ docs/          # Dökümanlar
 └─ build/         # ISO ve derleme çıktıları
